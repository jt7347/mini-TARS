# mini-TARS
Code for miniature TARS from Interstellar! WIP => working towards adding voice commands w/ LLM running onboard! The Vosk branch currently has the best response time (~3-5 seconds for stt and request, 3-4 seconds for tts), looking to give TARS a camera so it can see (llama3.2-vision was released but it takes too long to process with current API setup...).
